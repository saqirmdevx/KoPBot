# KoPBot
Discord Bot made for [Kingdom of Pixels](https://leagueofpixels.eu/) Server using:

- Python3
- SQLite3
- discord-interactions

It communicates with Discord API via wrapper libray, supports these funcionalities:
- Show number of users as Discord Status
- Assign XP and Levels based on server activity
- Store data about users between bot sessions
- Automatically assign roles based on User Level
- Display User Ranking
- Report user joining/leaving server
